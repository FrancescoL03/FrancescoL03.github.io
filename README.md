
# Portfolio personale - Francesco Lamanna

Questa repository contiene il codice sorgente del mio portfolio personale, realizzato per raccogliere e presentare il mio percorso formativo, le competenze acquisite e i progetti sviluppati durante gli studi universitari.

Attualmente frequento il corso di Laurea Magistrale in Informatica, curriculum **Data Science e Machine Learning**, presso l'Università degli Studi di Salerno.

## Sito web

Il portfolio è disponibile online al seguente indirizzo:

**[https://francescol03.github.io/](https://francescol03.github.io/)**

## Contenuti

Il sito è suddiviso in diverse sezioni:

- **Chi sono:** una breve presentazione personale e dei miei interessi.
- **Progetti:** alcuni dei lavori realizzati durante il percorso universitario.
- **Competenze:** linguaggi di programmazione, tecnologie e strumenti conosciuti.
- **Percorso:** il mio percorso di studi e di formazione.
- **Tesi triennale:** un approfondimento sul lavoro svolto per la laurea triennale.
- **Contatti:** collegamenti ai miei profili e recapiti.

## Tecnologie utilizzate

Il sito è stato realizzato utilizzando **HTML, CSS, JavaScript e React**, con **Vite** come strumento di sviluppo e compilazione.

La pubblicazione è gestita tramite **GitHub Pages**, con un workflow **GitHub Actions** per aggiornare automaticamente il sito.

## Esecuzione in locale

Per avviare il progetto in locale è necessario avere installato Node.js.

Dopo aver clonato la repository, eseguire i seguenti comandi:

```bash
npm install
npm run dev
```

Il sito sarà accessibile all'indirizzo locale mostrato nel terminale.

Per la realizzazione del portfolio ho utilizzato il supporto di ChatGPT, principalmente per la creazione della struttura e l'implementazione del codice. Ho curato personalmente la scelta dei contenuti, l'organizzazione delle informazioni e le successive personalizzazioni del sito.
